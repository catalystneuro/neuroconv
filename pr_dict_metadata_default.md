NeuroConv now fills its own metadata with the dict-based format. Every internal `metadata or self.get_metadata()` site asks for the new shape: `create_nwbfile` and `run_conversion` on both `BaseDataInterface` and `NWBConverter`, and the modality bases inside `add_to_nwbfile`. `get_metadata()` keeps handing users the old list-based shape, so a script that reads it, edits it and passes it back is untouched, and a converter mixing a dict-only interface with a dual-mode one now returns one consistent dictionary rather than two shapes in one dict. The point is sequencing. The dict format is what the interfaces have been migrating to since [#1815](https://github.com/catalystneuro/neuroconv/pull/1815), but nothing wrote it unless a caller opted in, which made it the least exercised path in the library while being the one everything is moving to. Making it the internal default is what turns supported into used, and it is deliberately the step before `get_metadata()` itself returns dict, which is the change users feel and wants its own release.

The tests move with it, because otherwise this PR would ship a green suite that was not exercising what it just made default. The shared mixins asked each interface for whatever `get_metadata()` returns, so the files they wrote were built from the old shape; they now ask for the format NeuroConv writes, which means every interface's file, on real data, comes from dict metadata. That is how the ophys dict-path defects fixed in the companion PR were found, and it is also why the old format now gets a deliberate suite of its own, one module per modality, writing user-stated values through `run_conversion`, `add_to_nwbfile` and a converter: the format is still supported, so it still has to be exercised on purpose rather than by accident. Where the two paths disagree the written file changes, and the changelog entry lists each difference. Builds on [#1865](https://github.com/catalystneuro/neuroconv/pull/1865), [#1867](https://github.com/catalystneuro/neuroconv/pull/1867) and [#1868](https://github.com/catalystneuro/neuroconv/pull/1868), and is independent of [#1870](https://github.com/catalystneuro/neuroconv/pull/1870).
