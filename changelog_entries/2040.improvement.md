Added `EventsInterfaceTestMixin` to `neuroconv.tools.testing.data_interface_mixins`, a `DataInterfaceTestMixin` whose round trip checks that every event type's written rows carry the times `get_event_times` reports, and moved the events test classes onto it. `DataInterfaceTestMixin` also gained an `edit_metadata` hook to shape the metadata the round trip writes, so a test class can write under the names a user would give the event types.
