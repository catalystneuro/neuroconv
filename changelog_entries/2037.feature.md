`ExternalVideoInterface` now holds the `alignment` surface, one object per video file keyed by the file stem. The surface gained `move_start_to(starting_time)`, which on `alignment[key]` places one object by its first sample without building its times and on `alignment` moves every object so the earliest start lands there, and `alignment[key].shift_times(delta)`, which shifts one object alone. Every video file now starts at the time its container stores for its first frame, usually zero, until it is placed, and several files that overlap raise when written, as several files with no timing information did before. The `set_aligned_*` methods and `get_timestamps` still work under a `FutureWarning` and will be removed in v0.12.0.
