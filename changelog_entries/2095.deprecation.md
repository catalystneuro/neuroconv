`GuppyInterface` and `GuppyConverter` now read the results layout GuPPy writes from [LernerLab/GuPPy#547](https://github.com/LernerLab/GuPPy/pull/547) on, where every results table is a CSV file and binned trials live in their own `binned_` files. Output folders from earlier GuPPy versions, which hold those tables as `.h5` files, are no longer read, and the `guppy` extra no longer installs `tables`.
