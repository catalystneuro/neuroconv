`configure_backend` no longer raises `NotImplementedError` on ndx-events 0.2 containers in a file read from disk without ndx-events 0.2 installed, such as one streamed from DANDI and read against its cached namespaces. Those containers are now recognized by their namespace and left unconfigured, at any installed ndx-events version or none, so the deprecated `MedPCInterface` no longer compresses the `Events` it writes.
