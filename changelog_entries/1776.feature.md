Added `neuroconv.tools.ontology`, offline resolution and HDMF HERD annotation of `Subject.species` (NCBITaxon) and anatomical `location` fields (Allen Mouse/Human Brain Atlas, with a UBERON fallback for other recognized species) across the electrodes table, `ElectrodeGroup`, `ImagingPlane`, `IntracellularElectrode`, `OptogeneticStimulusSite`, `FiberPhotometryTable`, and `ViralVectorInjection`. Resolution is split into two layers: `infer_species_ontology_metadata` / `infer_brain_region_ontology_metadata` guess a term from a free-text value and write it into one file-wide `metadata["ontology"]` block, keyed by the value it describes, while `add_species_external_resource` / `add_brain_region_external_resources` deterministically write whatever term is already stated in `metadata` into the file under `/general/external_resources`, requiring `pynwb>=4.0.0`. The curated vocabularies ship as LinkML TermSet YAML files, read without a `linkml-runtime` dependency. Values wrapped in an HDMF `TermSetWrapper` (when a type configuration such as neuro-termsets' is loaded) are annotated by their plain value.
