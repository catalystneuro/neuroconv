Added `neuroconv.tools.external_resources`, offline resolution and HDMF HERD annotation of `Subject.species` (NCBITaxon) and anatomical `location` fields (Allen Mouse/Human Brain Atlas, with a UBERON fallback for other recognized species) across the electrodes table, `ElectrodeGroup`, `ImagingPlane`, `IntracellularElectrode`, `OptogeneticStimulusSite`, `FiberPhotometryTable`, and `ViralVectorInjection`. Resolution is split into two layers: `infer_species_external_resources` / `infer_brain_region_external_resources` read a populated `NWBFile`, guess a term for each free-text value and return it as a file-wide `{"ExternalResources": {...}}` metadata block keyed by the value it describes, to be merged under the user's metadata, while `add_species_external_resource` / `add_brain_region_external_resources` deterministically write whatever term is already stated in `metadata` into the file under `/general/external_resources`, requiring `pynwb>=4.0.0`. The curated vocabularies ship as LinkML TermSet YAML files, read without a `linkml-runtime` dependency. Values wrapped in an HDMF `TermSetWrapper` (when a type configuration such as neuro-termsets' is loaded) are annotated by their plain value.
