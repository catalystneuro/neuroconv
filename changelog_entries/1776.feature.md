Added `neuroconv.tools.external_resources.add_external_resources_to_nwbfile`, which writes the ontology terms stated in `metadata["ExternalResources"]` into the file as HDMF HERD references under `/general/external_resources` (requires `pynwb>=4.0.0`). The `species` map annotates `Subject.species`, and the `anatomical_structures` map annotates the anatomical `location` fields of the electrodes table, `ElectrodeGroup`, `ImagingPlane`, `IntracellularElectrode`, `OptogeneticStimulusSite`, `FiberPhotometryTable` and `ViralVectorInjection`. `run_conversion` calls it just before writing, in write and append mode. Values wrapped in an HDMF `TermSetWrapper` (when a type configuration such as neuro-termsets' is loaded) are annotated by their plain value.
