The Zarr backend now writes with zarr 3, so it requires Python 3.14 or newer and raises `NotImplementedError` on older Pythons, where neuroconv still installs zarr 2; `AVAILABLE_ZARR_COMPRESSION_METHODS` and `AVAILABLE_ZARR_FILTER_METHODS` now hold zarr 3 codecs, and `categorize`, which has none, is no longer accepted.
