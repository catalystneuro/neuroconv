The Zarr backend now works on every supported Python, not only 3.14. `ZarrDatasetIOConfiguration` gains a `shard_shape` field that writes a dataset as zarr 3 shards, each holding a whole number of chunks along every axis (default `None`, no sharding). `NeuralynxRecordingInterface` and `NeuralynxSortingInterface` gain `gap_tolerance_ms`: neo 0.14.6 raises on timestamp gaps in NCS files, and a value in milliseconds ignores gaps shorter than it and starts a new segment at longer ones.
