The Figshare download helpers in `neuroconv.tools.figshare` now work outside Jupyter. The progress bar came from `tqdm.notebook`, which raises where `ipywidgets` is absent, so `download_collection` failed before transferring anything; `requests`, which neuroconv does not declare, is now imported on first use with an install hint rather than at import time, and a destination whose parent folder does not exist is created rather than refused.
