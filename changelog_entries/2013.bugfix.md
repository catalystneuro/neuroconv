`get_default_dataset_io_configurations` now auto-detects the backend of a file opened for appending when `backend` is left as `None`, as its docstring and error messages have said. The configuration class was looked up from `backend` before the detection ran, so `None` raised `KeyError` instead. The guard for a file read without appending also no longer reads an attribute `NWBZarrIO` lacks, and its message now describes that case.
