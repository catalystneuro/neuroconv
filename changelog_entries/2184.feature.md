Intracellular interfaces can now write a stimulus template, the command the protocol specified, beside the recorded stimulus by returning it from `_get_icephys_stimulus_template_data` on `BaseIcephysInterface`, with its metadata in `metadata["Icephys"]["PatchClampStimulusTemplateSeries"]`. The template is written relative to its own start, stores each distinct sweep waveform once, and is keyed by waveform and electrode, so interfaces that name the same entry share one series.
