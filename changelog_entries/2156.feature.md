The sorting interfaces take a `metadata_key`, defaulting to a constant per format such as `kilosort_sorting`, which addresses the sorting's entry in `metadata["Ecephys"]["Sortings"]`. That entry's `units_table_metadata_key` names the table the sorting writes into, declared in `metadata["Ecephys"]["UnitsTables"]` with its `name` and `description`, so several sortings can write into one table.
