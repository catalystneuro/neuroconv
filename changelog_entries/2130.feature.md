The recording interfaces now support `interface.temporal_alignment`, with one time-bearing object per segment keyed `{metadata_key}_{segment_index}`, the key that overrides the segment's metadata, so each segment can be shifted, placed with `move_start_to`, given replacement timestamps or remapped. A write warns when a segment after the first has no start time in the source and nothing placed it, since it is written from zero and may overlap the first.
