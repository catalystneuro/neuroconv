The `neuroconv` command line entry point no longer fails with `AttributeError: 'str' object has no attribute 'parent'` when `--output-folder-path` is not given, and a session's `nwbfile_name` keeps its leading and trailing `n`, `w` and `b` characters: the `.nwb` suffix was removed with `str.strip`, which strips characters rather than a suffix, so `brain_waves.nwb` was written as `rain_waves.nwb`.
