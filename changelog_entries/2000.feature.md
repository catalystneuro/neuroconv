`GuppyInterface` now writes the outputs of GuPPy's bootstrap PSTH significance testing as `ndx-guppy` `GuppyPSTHSignificance` objects: the estimate, both confidence bounds and the significance flags over the peri-event window, one object per (recording site, trace type, comparison kind), with the event pairs compared against each other kept separate from the tests against zero. It is written only for a session that ran that optional GuPPy step.
