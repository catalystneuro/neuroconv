`add_imaging_to_nwbfile` and `add_segmentation_to_nwbfile` now emit a `FutureWarning` when metadata with keyed `MicroscopySeries` or `PlaneSegmentations` entries is passed without `metadata_key`. Starting in v0.13.0 this will raise a `ValueError` instead of falling back to the `"default_metadata_key"` entry: pass `metadata_key` explicitly, or pass no metadata to write with default metadata.
