A `DeepDict` now stores every dict value as a `DeepDict`, whether it arrives through the constructor, item assignment, `update` or `deep_update`. A dict stored through assignment or `update` stayed a plain dict, so a later `deep_update` into that key raised `AttributeError`, and an assignment below it, `metadata["Subject"] = {...}` followed by `metadata["Subject"]["x"]["y"] = 1`, raised `KeyError`. `AudioInterface.get_metadata` builds its `Behavior` block through `update`, so that block was a plain dict.
